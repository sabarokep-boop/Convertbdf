# حوّل ملفك — دليل التشغيل

## المتطلبات
سيرفر VPS (Ubuntu 22/24) بذاكرة 4GB أو أكثر، ودومين موجّه عليه (سجل A).

## الخطوات
1. ثبّت Docker: `curl -fsSL https://get.docker.com | sh`
2. ارفع مجلد المشروع للسيرفر.
3. `cp .env.example .env` ثم عدّل `DOMAIN=` لدومينك.
4. شغّل: `docker compose up -d --build` (أول بناء ياخذ عدة دقائق).
5. افتح `https://دومينك` — الشهادة (HTTPS) تتفعل تلقائيًا.

## وش يشتغل وين
- على السيرفر: Word/Excel/PowerPoint إلى PDF، PDF إلى Word، ضغط PDF، OCR.
- داخل المتصفح: الصور إلى PDF، PDF إلى صور، الدمج، استخراج النص.
- لو السيرفر وقف، Word/Excel/PDF-إلى-Word يرجعون تلقائيًا للتحويل داخل المتصفح (أضعف جودة).

## الضبط (docker-compose.yml)
- `MAX_MB` أقصى حجم ملف. `CONCURRENCY` عدد التحويلات المتزامنة (خله بعدد أنوية المعالج تقريبًا).
- الملفات تنحذف بعد التحويل مباشرة، وأي مجلد عالق ينحذف بعد ساعة.

## اختبار لازم تسويه قبل الإطلاق
جرّب ملفات عربية حقيقية (Word فيه جداول وصور، Excel، PowerPoint) وقارن الناتج. جودة PDF إلى Word تعتمد على تعقيد الملف.

## قبل تفعيل الإعلانات
أضف صفحتي سياسة الخصوصية وشروط الاستخدام (AdSense يطلبهم)، وسجّل الموقع في Google Search Console.
