# حوّل ملفك — دليل التشغيل

## المتطلبات
سيرفر VPS (Ubuntu 22/24) بذاكرة 4GB أو أكثر، ودومين موجّه عليه (سجل A).

## الخطوات
1. ثبّت Docker: `curl -fsSL https://get.docker.com | sh`
2. ارفع مجلد المشروع للسيرفر.
3. `cp .env.example .env` ثم عدّل `DOMAIN=` لدومينك.
4. شغّل: `docker compose up -d --build` (أول بناء ياخذ عدة دقائق).
5. افتح `https://دومينك` — الشهادة (HTTPS) تتفعل تلقائيًا.

## وش يشتغل وين
- على السيرفر: Word/Excel/PowerPoint إلى PDF، PDF إلى Word، ضغط PDF، OCR.
- داخل المتصفح: الصور إلى PDF، PDF إلى صور، الدمج، استخراج النص.
- لو السيرفر وقف، Word/Excel/PDF-إلى-Word يرجعون تلقائيًا للتحويل داخل المتصفح (أضعف جودة).

## الضبط (docker-compose.yml)
- `MAX_MB` أقصى حجم ملف. `CONCURRENCY` عدد التحويلات المتزامنة (خله بعدد أنوية المعالج تقريبًا).
- الملفات تنحذف بعد التحويل مباشرة، وأي مجلد عالق ينحذف بعد ساعة.

## اختبار لازم تسويه قبل الإطلاق
جرّب ملفات عربية حقيقية (Word فيه جداول وصور، Excel، PowerPoint) وقارن الناتج. جودة PDF إلى Word تعتمد على تعقيد الملف.

## قبل تفعيل الإعلانات
أضف صفحتي سياسة الخصوصية وشروط الاستخدام (AdSense يطلبهم)، وسجّل الموقع في Google Search Console.

## تجهيز أدسنس
1. عدّل `public/config.js` (اسمك، بريد الدعم، واتساب، المدينة). كل الصفحات والفوتر تتحدث تلقائيًا.
2. أنشئ بريد دعم على دومينك (مثل support@دومينك.com).
3. بعد ما يعطيك أدسنس كودك: الصقه في وسم head داخل `public/index.html` وكل ملفات `public/*.html` (مكانه معلّم بتعليق).
4. حط رقمك في `.env`: `ADSENSE_PUB=pub-1234567890123456` ثم `docker compose up -d`، وملف `/ads.txt` يتولد تلقائيًا.
5. `/robots.txt` و`/sitemap.xml` يتولدون تلقائيًا من الدومين. أرسل الـ sitemap في Search Console.
6. للزوار من أوروبا (EEA) فعّل رسالة الموافقة المعتمدة من جوجل داخل حساب أدسنس.

## النشر على GitHub Pages (بدون استضافة مدفوعة)
1. اشترِ الدومين، ثم شغّل: `./set-domain.sh دومينك.com` (يضبط الروابط وصور المشاركة وCNAME وrobots وsitemap). بعد موافقة أدسنس أعد تشغيله برقمك: `./set-domain.sh دومينك.com pub-XXXXXXXXXXXXXXXX` — لكن يستبدل نصوص `__DOMAIN__` فقط أول مرة، فلو غيّرت الدومين لاحقًا عدّل الملفات يدويًا.
2. ارفع **محتوى مجلد public** (مو المجلد نفسه) إلى مستودع GitHub، ثم Settings ← Pages ← اختر الفرع.
3. في Pages اكتب دومينك في Custom domain وفعّل Enforce HTTPS.
4. عند مسجّل الدومين أضف سجلات DNS حسب توثيق GitHub Pages (أربعة سجلات A لـ GitHub، وسجل CNAME لـ www). تأكد من القيم الحالية من صفحتهم الرسمية.
5. في هذا الوضع (`api:false` في config.js) كل التحويل داخل المتصفح، وضغط PDF وOCR غير متاحين. لتفعيلهم تحتاج VPS وDocker كما فوق.

## صفحات الأدوات (للظهور في البحث)
كل أداة لها صفحة مستقلة (مثل `/pdf-to-word` بعنوان «تحويل PDF إلى وورد Word») وفيها الأمر مكتوب جاهز، فالزائر يرفع الملف ويضغط «حوّل» فقط. لتعديل نصوص الصفحات عدّل `build-tools.py` ثم شغّله **قبل** `set-domain.sh`.
